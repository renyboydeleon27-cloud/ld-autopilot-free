One-time Google setup
  1. Open Google Cloud Console and create or choose a project.
  2. Enable YouTube Data API v3 and YouTube Analytics API.
  3. In Google Auth Platform, configure Branding, Audience and Data Access. For personal testing, add the Google account that owns your channel as a test user. Add the youtube.readonly and yt-analytics.readonly scopes. Broader use may require Google verification.
  4. Create a Web application OAuth client. Add this exact Authorized JavaScript origin: . Use only the origin, without the page path. This popup connection needs no redirect URI.
  5. The LD AUTO Web OAuth Client ID is already configured. The field below is kept only for troubleshooting or replacing the client later. Never enter a client secret or API key.

Privacy & connection help

Google account authorization is handled by Google. Your access token and channel reports stay in memory in this open tab; they are not saved to LD AUTO servers or included in production backups. Only the OAuth Client ID is saved on this device. Closing the page clears the token and reports.

Disconnect clears the displayed data and, when possible, revokes this app's Google access. You can also remove access in Google account connections. This page uses YouTube API Services: YouTube Terms · Google Privacy Policy.

If Google says access is blocked, check your test-user account and OAuth setup. If it reports an origin mismatch, copy the exact origin shown above. Use your channel owner's Google account, enable popups, and open in your normal browser if the installed app cannot show Google sign-in.
