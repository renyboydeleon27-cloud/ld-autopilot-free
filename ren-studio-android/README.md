# REN STUDIO Android

Standalone Android wrapper for the independent AI Drama and Anime Adventure workspaces.

- Package: `com.renstudio.app`
- App name: **REN STUDIO**
- Minimum Android: 7.0 (API 24)
- Target: Android API 35
- AI polishing remains online and uses the existing Vercel API.
- WebView storage is app-local, so fiction project data is separate from Chrome / the Living Disaster workspace.

Build:
```
gradle assembleDebug
```

APK:
`app/build/outputs/apk/debug/app-debug.apk`
