# LD Autopilot Free

Free, image-and-prompt-first production dashboard for the Living Disaster Book workflow.

## Locked production formats

- Shorts: portrait 9:16, HOOK + P1-P14 + ENDING + THUMBNAIL (17 stages)
- Longform: landscape 16:9, HOOK + S1-S30
- Adult characters only
- Serious colored historical graphic-novel/anime style
- No photorealistic humans, no live action, no 3D CGI people
- ENDING and THUMBNAIL are illustration-only
- No automatic video generation in v1
- No paid APIs in v1

## v1 goal

Track project format, disaster topic, stage status, narration, image prompts, and Flow animation prompts locally in the browser with no paid integration required.
