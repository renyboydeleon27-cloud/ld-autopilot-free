# LD Editor Lab

Experimental standalone Living Disaster Book video editor.

## v0.1.0
- Local browser-only clip loading
- Auto-detect HOOK, P1–P14, ENDING from filenames
- Fixed LD timeline
- Per-clip duration/timing review
- Full sequence preview
- Optional full narrator audio track
- Optional background music
- Clip/SFX volume control
- Simple music ducking when narrator is present
- Experimental local 9:16 WebM render
- No OpenAI/API calls in this version

This folder is intentionally not imported by the main LD AUTO application, so the editor does not add startup/runtime load to LD AUTO.

Future: AI final-clip analyzer, exact narration generator, AI narrator, MP4 export, captions and smart cuts.
